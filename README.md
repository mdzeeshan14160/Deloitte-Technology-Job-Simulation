# Deloitte Technology Virtual Job Simulation

Completed the **Deloitte Technology Virtual Experience Program** on **Forage**.

This project contains the work completed during the simulation, including JSON data transformation using Python and a software development proposal.

## Tasks Completed

### Task 1 — JSON Data Transformation

Worked with two different JSON data formats and transformed the data into a common structure.

**Work completed:**
- Read and processed JSON data using Python.
- Converted the first data format into the required output structure.
- Converted the second data format into the same target structure.
- Transformed device information such as device ID and device type.
- Converted timestamps into epoch milliseconds.
- Restructured location information into nested fields.
- Mapped fields such as `operationStatus` to `data.status` and `temp` to `data.temperature`.
- Used unit tests to compare the transformed results with the expected output.

### Task 2 — Software Development Proposal

Prepared a software development proposal based on the simulation requirements.

The proposal document covers the planned solution, including the proposed dashboard/software approach and related development considerations.
